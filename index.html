COLDEX Sample Finder

To learn more about COLDEX ice cores, visit the COLDEX ice core information page. To request samples, follow instructions here. This database is updated in coordination with the National Ice Core Facility after each field season and again after each CPL. Please contact the data manager if you see any errors.

How to use: Select one or more core IDs (hold Cmd/Ctrl to select multiple). Optionally set depth filters and choose a sample status. Click Search to view matching results, or Download CSV to export your data. Click on Record ID or Core ID buttons for subsample information and core metadata.
