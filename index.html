COLDEX Sample Finder

About this site & how to use it

This site has two tabs. Use the tabs below to switch between them:

Interactive Map

Explore where each core was drilled in the Allan Hills.

  • Hover over a core on the map to see its ID, year drilled, depth, diameter, age and description.
  • Blue dots are COLDEX cores; orange dots are non-COLDEX cores.
  • Open the table at the bottom of the map to compare all COLDEX cores. Click a core ID for its full metadata.
Sample Finder

Search the sample database and export what you find.

  • Select one or more core IDs (hold Cmd/Ctrl to select several). Optionally set depth filters and a sample status.
  • Click Search to list matching samples, or Download CSV to export them.
  • Use Show subsamples sent to to see which subsamples went to which institution.
  • In the results, click a Record ID or Core ID button for subsample information and core metadata.

To learn more about COLDEX ice cores, visit the COLDEX ice core information page. To request samples, follow instructions here. This database is updated in coordination with the National Ice Core Facility after each field season and again after each CPL. Please contact the data manager if you see any errors.
